# 潮切

中文名：**潮切** · 前缀 `tide` · 端口 **7900**

## 骨架（新骨，不是闸对/对拍/缝包换皮）

**观测点装载 → 事件时入窗缓冲 → 关窗物化切片 → 迟到/乱序旁路 → 窗账与缓冲互证**

| 对比 | 闸对 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→开腿→成对 | 双轨装载→键对齐 | **单流入→入窗缓冲→关窗物化** |
| 在途 | 开腿账 | 悬账单（对齐后） | **入窗缓冲（未关窗）** |
| 产物 | 行程账 | 对齐差+结论 | **窗切片账** |
| 旁路 | 旁路匣 | 悬账/缺边 | **迟到匣（事件时出窗）** |

皮：物流网点运单轨迹上报。去皮：**事件时关窗管道 + 缓冲 + 迟到旁路 + 窗贯验**。  
禁止做成运单 CRUD、配送看板、工单系统。禁止抄闸对开腿/对拍左右轨命名。

## 页面（真翻页）

## 多源串扰隔离（已接线）

东站、西港两网点源上报同一运单键，关窗物化必须选定工程形态，窗规键 `多源隔离策略` 钉死、可在网点源页切换：

| 形态 | 切片键 | 同运单切片行数 | 源明细 |
| --- | --- | --- | --- |
| 复合隔离（默认） | 窗号+源键+运单键 | 两源两行片 | 片行自带源键 |
| 运单合并 | 窗号+运单键 | 现行一片 | 只读表 `多源归档`，下游读归档区分来源 |

- 装载：网点源未登记即驳回，回执带 `按源入缓冲`。
- 关窗：`关窗锁` 互斥（`BEGIN IMMEDIATE`），按源汇总再物化，单事务同成同败；缺互斥的并发关窗必被拒，不会混成无归档的单行片。
- 贯验：附加多源不变量检查（复合片缺源键、合并片缺/错归档、归档悬挂均判不对齐）。
- 只读接口：`GET /api/多源隔离`（运单键/源列表/片行数/valid）、`GET /api/多源隔离/归档`、`POST /api/多源隔离/策略`。
- 夹具：`fixtures/多源同运单样例.json`（两源同运单各一笔 + 单源对照）。
